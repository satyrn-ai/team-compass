# Engine Team Update 2026-09-28

A lot of work has gone into both repos to bring them to a usable 0.1 release. Most notably work from @pauleveritt:

- Loosened overly strict isolation guarantees — the model still runs safely, but no longer under rules so rigid they made the tool hard to use in everyday
work.
- Added Linux and Mac support — so people can run it on the machines they already use, not just one platform.
- Wrote documentation aimed at newcomers, not just specialists deep in the field.
- Changed engine's /implement command to a more lenient state.

Together, these changes move the project towards something practical and approachable.
