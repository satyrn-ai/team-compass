# Engine Team Update 2026-08-17

First of all, a warm welcome to the new co-lead of the Engine Team, @hixi

During the last week, a repo for evals was created: <https://github.com/satyrn-ai/satyrn-evals>
The main idea of this repo is to gather all the diverse use cases of the Satyrn community and turn them into evals. This will allow us to test different harness configurations and models against real-world workflows and make sure they continue to work well as the project evolves.
So, if you have any use cases that you would like to make sure Satyrn handles well, please share them. You can do so by adding them directly to the <https://github.com/satyrn-ai/satyrn-evals> repo, creating an issue or discussion in this repo, or commenting in this thread: <https://discord.com/channels/1527699615262965905/1533888267550724196> with the description of the use case, for it to be added to the evals
