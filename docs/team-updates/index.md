# Weekly team updates

Team leads post weekly updates here as Markdown files. Merging an update to `main`
automatically announces it in Discord.

## Posting an update

1. Add a new file under `docs/team-updates/<team>/` (e.g. `docs/team-updates/engine-team/2026-08-22.md`).
2. Start the file with a top-level heading (`# ...`) — this becomes the Discord announcement title.
3. Open a PR and merge to `main`. The [`sync_team_updates_discord`](https://github.com/satyrn-ai/team-compass/blob/main/.github/workflows/sync_team_updates_discord.yml) workflow will post a link to the update in Discord.
