# Models Team update 2026-08-17

## Key takeaway

We managed to generate datasets and fine-tune our first models (Qwen and Mellum) to correctly answer Python 3.15 questions!

**Training pipeline is ready!**

## Some details

- Our first workshop meeting happend
- First PRs from more team members landed
- Dataset generators built
  - CPT - simple, converts CPython/PEP docs to Markdown text data
  - SFT - DeepSeek-based, LLM generates prompt/response ideas, sandbox-verified code, LLM-as-judge filtering. Runs using 500 concurrent workers 😉
- Datasets prepared for both Python 3.14 and 3.15, ~1500 SFT examples per version, ~2.0M tokens total
- Reasoning traces added to SFT generation, needed to train thinking models
- Unsloth trainer configured for real models - Mellum 2, Gemma 4, Qwen 3.6 and Qwen3-Coder
- MLflow tracking working end to end - nested runs per stage, eval loss, logs and trained LLM-conversation traces
- Basic Q/A evaluation step: ask model 3 questions which require latest Python knowlege.
- CI in Models repo - ruff liniting plus basic smoke unit-tests
